----------------------------------------------------------------
SE PERGUNTAREM  — respostas curtas
----------------------------------------------------------------

"Dá para outro terminal no mesmo sistema?"
  Sim. Cada terminal é um cadastro com os dados e as chaves
  dele (NFS-e, e-mail, certificado). A RL que vocês viram
  é o primeiro. Isolamento fino entre vários no mesmo
  servidor entra na implantação em nuvem, não nesta demo.

"Aluguel e pátio da mesma caixa?"
  São dois IDs. O cliente pode alugar, levar no caminhão e
  depois hospedar no pátio. Gate e pátio só olham o ID de
  pátio. A fatura do mês pode juntar os dois IDs no
  demonstrativo — uma NFS-e, um cliente.

"E a nota fiscal?"
  NFS-e municipal (IPM / Atende.net, Navegantes) e, se
  falhar, Emissor Nacional (gov.br) com certificado A1.
  Hoje não emitimos ao vivo para não gerar nota de verdade.

"O mapa do pátio é esse?"
  O cadastro de posição é a lista (MDM). O mapa visual fica
  no app do operador — ainda não é esta tela. O saldo e o
  dossiê já operam.

"E se a internet cair?"
  Gate, pátio e RIC rodam no servidor local. Foto e mapa
  sentem a rede. A máquina de hoje é laboratório; produção
  vai para nuvem com backup.

"Quanto custa a diária / o plano?"
  Não inventar preço. "Tabela por cliente, cadastrada.
  Plano STANDARD / PREMIUM / ENTERPRISE é rótulo — o que
  vocês viram é o pacote operacional completo."

"Dá para o comprador acessar de casa?"
  Se combinamos HTTPS e só a porta do site, sim. Super Admin
  fica fechado. Este PC não vai nu para a internet.
